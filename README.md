# 水文监测站网管理系统

面向水文监测站点运行、水位流量雨量数据采集、遥测设备维护与数据整编发布的水文站网管理平台。

这是一个**纯前端**管理平台：Vue 3 + Vite + TypeScript，仓库里没有后端服务。业务数据由
`frontend/src/data/` 下的本地数据层提供：首次打开用示例数据播种，之后的登记、筛选与状态流转
结果都持久化在浏览器 `localStorage` 里，刷新或重开浏览器都还在。dev server 已关掉自动打开页面，
启动后按终端打印的地址手工打开。

## 目录结构

```text
.
├── frontend/                 Vue 3 + Vite + TypeScript 前端（唯一运行单元）
│   ├── src/views/            每个业务模块一个页面
│   ├── src/api/local-service.ts   本地数据服务：列表、筛选、动作流转、导出
│   ├── src/data/             模块元数据 / 示例数据 / localStorage 持久化
│   ├── src/stores/           会话与筛选状态
│   └── vite.config.ts        dev server 配置（open: false，无 /api 代理）
├── .gitignore
└── docker-compose.yml
```

## 启动

```bash
cd frontend
npm install
npm run dev
```

前端默认监听 `http://127.0.0.1:5173/`，dev server 不会自动打开浏览器，需要自己访问。

生产构建：

```bash
cd frontend
npm run build
```

## 通讯设备故障判级规则台

侧边栏「故障判级规则台」（路由 `/comm-grading`），代码在
`frontend/src/data/comm-grading/`。规则全部在 `rules.ts` / `service.ts` 里，页面只做渲染。

判级输入为设备编号、所属站点、通讯协议、信号阈值读数与最近通讯时刻，输出五级结论：

| 等级 | 判定条件（阈值按协议配置，台面可改） | 建议 |
| --- | --- | --- |
| 通讯正常 | 信号高于弱信号阈值，且未超静默时长 | 维持现有巡检频次 |
| 信号弱 | 信号 ≤ 弱信号阈值（4G 默认 -95dBm） | 调整天线、检查馈线，持续观察 |
| 建议中断核查 | 最近通讯时刻距今超过静默阈值（4G 默认 30 分钟） | 核实链路中断、天线供电，下站排查 |
| 建议更换 | 信号 ≤ 更换阈值（4G 默认 -110dBm） | 通信模块疑似老化，建议更换设备 |
| 缺读数待补 | 信号或最近通讯时刻读不出 | 不自动判级，人工补录后重新判级 |

配套规则：

- **自动与人工冲突以人工为准**：人工判断保存即为生效结论；自动判级与人工结论冲突时，自动结论
  只留痕（`effective=false`），不生成核查事项。
- **停用设备不允许保存新结论**：自动、人工入口都拦截；停用只清在途上报锁，历史结论保留。
- **巡检链路同步**：建议中断核查 / 建议更换的生效结论自动在「巡检记录」页生成通信核查事项；
  人工改判正常/弱信号时自动关闭该设备待核查事项；同设备同等级不重复开单。
- **同一设备重复并发上报只接受一个结论**：判级按轮次（round）进行，每设备每轮首个结论生效并加
  10 分钟持久化上报锁（刷新页面仍拦截），重复上报直接丢弃；「并发上报×5」按钮可压测验证。
- **历史缺读数迁移**（已定案）：首次进入判级台时，把旧「通讯系统」清单整体迁入，信号强度/最近
  通讯时刻为占位文本或空值的设备**原样保留、不填零、不丢弃**，标「缺读数待补」逐台补录；迁移
  台账在台面横幅留痕。判级台数据独立存放在 `hydrology-monitor-station:comm-grading`。
- 协议阈值内置 4G / 5G / NB-IoT / 北斗卫星 / 超短波五套，可在台面调整或新增；信号支持
  `-95`、`-95dBm`、`72%` 三种写法（百分比按 -113～-55dBm 折算）。

## 约定

- 每个模块的页面在 `frontend/src/views/<模块>/index.vue`，页面只负责渲染，读写统一走
  `frontend/src/api/local-service.ts`。
- 字段、状态、动作与流转目标集中在 `frontend/src/data/modules.ts`；示例数据在
  `frontend/src/data/seed.ts`。
- 状态流转只允许在 `local-service.ts` 里改，页面组件不做业务判断。
- 想回到初始数据：清掉浏览器里 `hydrology-monitor-station:entries` 这一项，或调用 `resetModule(模块)`。
  判级规则台的独立数据键为 `hydrology-monitor-station:comm-grading`（台面右上角「重置判级台」等效）。
- 判级台业务规则冒烟测试（无需浏览器，esbuild 即时转译 + 内存 localStorage）：
  `node frontend/scripts/comm-grading-smoke.cjs`。
